# todo-app (example)

This is a sample project demonstrating what a repo using `loom-spec` looks like. It contains:

- `.loom/` — the architecture spec (node-types, diagrams).
- `.claude/skills/loom-spec/` — the agent skill that tells Claude Code how to maintain the spec.

There is no actual application code here — this exists purely as a fixture for developing and testing `loom-spec`.
